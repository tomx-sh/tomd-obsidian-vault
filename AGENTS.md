# Vault instructions
This vault is published to the internet with [Obsidian Publish](https://obsidian.md/help/publish) feature.

Home page is [[index]].

It is fully in English.

'not-published' directory is not published. Use it for drafts or internal notes. You should add frontmatter `publish: false`property too.

When embedding an image, the file should be moved inside the vault 'images' directory.

# Articles
The main content of this website is inside the 'articles' directory. It contains blog articles, often as tutorials.

They should have a neutral tone, and be written in a way that allows the reader to understand and follow the tutorial. So they should contain all necessary context or link to other articles.

When possible, add links to other articles to create a nice graph.

They should not be too specific to the writer's setup, if possible. They should be concise, straight to the point.

When writing an article, make sure its link is added to [[articles/index]], in an appropriate section.

Add the following frontmatter properties:
```
---
publish: true
created: 2026-07-30
---
```
